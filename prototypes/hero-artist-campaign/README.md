# HERO Artist Campaign Prototype

Standalone prototype for HERO's public LAMBO CITY VOL 1 release campaign.

- Public album links: Apple Music and Amazon Music.
- Manual audience/stream milestone inputs with a local celebration preview.
- Draft campaign opportunity categories.
- Separate notes for documenting verified ASCAP / LAMBO CITY Radio outcomes.

This is a front-end concept only. It has no backend, login, platform API, automatic metrics, live applications, payments, or royalty integration. Metrics start blank and are not transmitted or saved. It does not modify the Three.js game entry point.

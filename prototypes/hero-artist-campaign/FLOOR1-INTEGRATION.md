# HERO Career Center — Floor 1 prototype

## What this adds
- A touch-friendly **CAREER CENTER** prompt when the player approaches the existing Floor 1 left-wall artwork/media display.
- Keyboard **E** interaction using the existing game input system.
- A responsive campaign panel with HERO's confirmed *LAMBO CITY VOL 1* Apple Music and Amazon Music links.
- Clearly labeled sections for milestones, verified achievements, and future player opportunities.
- Escape key, close button, and backdrop-click dismissal.

## Placement and preservation
The interaction is anchored near the existing Floor 1 video/artwork wall (HQ world coordinates approximately X 22.3, Z 21.0). It does not create or move architecture, change the elevator, change collision, alter player movement, or modify Floor 2 audio/studio systems.

## Important scope limits
This is the first in-game front-end shell, not a completed live career platform. Milestone data is intentionally not fabricated. Evidence submission/review, shared accounts, authenticated reviewer roles, server persistence, public-platform API connections, real-time Jumbotron triggers, and player opportunity fulfillment are not connected in this prototype. Royalty amounts and game rewards remain separate.

## Test checklist
1. Open the game using this branch in a local preview.
2. Enter Records HQ Floor 1 and approach the existing left-wall artwork/media screen from the room side.
3. Confirm the **CAREER CENTER** prompt appears within interaction range.
4. Tap the prompt on touch devices or press **E** on keyboard.
5. Confirm the panel displays HERO / *LAMBO CITY VOL 1* and both music links open their intended services.
6. Close with the close button, backdrop tap/click, or Escape.
7. Walk away and confirm the prompt disappears.
8. Re-test Floor 1 media, merchandise interaction, elevator access, Floor 2 studio, and music playback.

No change is deployed or merged to `main` by this branch.
